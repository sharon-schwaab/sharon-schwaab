## 🚀 Featured Projects

### 🛴 [Gans E-Scooter ETL Pipeline](https://github.com/sharon-schwaab/gans-etl-pipeline-python-mysql)

**Python · REST APIs · BeautifulSoup · SQLAlchemy · MySQL**

Automated ETL pipeline combining city, weather and flight data from multiple sources in a normalised relational database.

The project connects **web scraping, APIs, data transformation and database engineering** to create a reusable data foundation for analysing e-scooter demand.

---

### 📊 [Eniac Discount Strategy Analysis](https://github.com/sharon-schwaab/eniac-discount-analysis)

**Python · Pandas · Seaborn · Matplotlib**

Analysis of more than **226,000 e-commerce orders** investigating whether deeper discounts actually increase sales.

The project required extensive **data cleaning and validation** before analysing pricing behaviour, seasonality and the relationship between discount depth and sales volume.

**Key finding:** No measurable relationship between deeper discounts and higher sales volume was found in the analysed data.

---

### 🗄️ [Eniac–Magist Partnership Analysis](https://github.com/sharon-schwaab/sql_business_exploration)

**SQL · MySQL · Tableau**

Business analysis evaluating whether an e-commerce marketplace provides a suitable environment for Eniac's premium technology portfolio.

SQL was used to explore **product performance, pricing, revenue, seller development and delivery behaviour**, with the results communicated through Tableau visualisations and a final business presentation.

The project demonstrates how relational data can be transformed into **evidence for strategic decision-making**.
